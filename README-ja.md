## 教育の規範

- [ECA](https://go.mymarketing.click/iaaula-eca) - 児童・青少年法（ECA）。 `公式` `無料`
- [LDB](https://go.mymarketing.click/iaaula-ldb) - 教育指針と基本法（LDB）。 `公式` `無料`
- [Lei Brasileira de Inclusão](https://go.mymarketing.click/iaaula-lei-brasileira-de-inclusao) - 障害のある人のための法律（Estatuto da Pessoa com Deficiência）、適応活動の基礎。 `公式` `無料`

## タグ

各項目には何であるかが書かれています。隣のタグは選ぶ際の助けになります。標準を定める側から出ているものは公式、コードが公開されているものはオープンソース、利用方法による無料か有料か、統合の方法によるAPIとSDKです。「作者本人の」タグが付いた項目はCiro Cesar Macielが作成したもので、他のすべての項目と同じルールに従います。
