## Cadre de l'éducation

Ce qui définit le programme, les droits de l'élève et le travail de l'enseignant.

- [BNCC](https://go.mymarketing.click/iaaula-bncc) - La Base nationale commune curriculaire, dans le document du MEC. `officiel` `gratuit`
- [ECA](https://go.mymarketing.click/iaaula-eca) - Le Statut de l'enfant et de l'adolescent. `officiel` `gratuit`
- [LDB](https://go.mymarketing.click/iaaula-ldb) - La loi des directives et bases de l'éducation. `officiel` `gratuit`
- [Lei Brasileira de Inclusão](https://go.mymarketing.click/iaaula-lei-brasileira-de-inclusao) - Le Statut de la personne handicapée, base de l'activité adaptée. `officiel` `gratuit`
- [Lei do piso do magistério](https://go.mymarketing.click/iaaula-lei-do-piso-do-magisterio) - La loi 11.738/2008, qui institue le salaire plancher de l'enseignant. `officiel` `gratuit`

- [ANPD](https://go.mymarketing.click/iaaula-anpd) - L'Autorité nationale de protection des données, avec guides et règlements de la LGPD. `officiel` `gratuit`

## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand il vient de l'organisme qui définit le standard, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les éléments avec l'étiquette "de l'auteur" sont faits par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
