Для преподавателей базового образования, которые хотят использовать ИИ при составлении плана урока, проверке работ и адаптированных заданий, не раскрывая данные учеников. Здесь собраны ассистенты, условия по возрасту и конфиденциальности каждого из них и нормы образования, по которым можно проверить, что действует.

## Метки

Каждый пункт описывает, что это такое. Метки рядом помогают выбрать: официальный, если это от тех, кто задаёт стандарт, открытый код, если код опубликован, бесплатно или платно по модели использования, API и SDK по способу интеграции. Пункты с меткой "от автора" сделаны Ciro Cesar Maciel и подчиняются тем же правилам, что и все остальные.
