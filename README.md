## Normas da educação

O que define o currículo, os direitos do aluno e o trabalho do professor.

- [BNCC](https://go.mymarketing.click/iaaula-bncc) - A Base Nacional Comum Curricular, no documento do MEC. `oficial` `grátis`
- [ECA](https://go.mymarketing.click/iaaula-eca) - O Estatuto da Criança e do Adolescente. `oficial` `grátis`
- [LDB](https://go.mymarketing.click/iaaula-ldb) - A Lei de Diretrizes e Bases da Educação. `oficial` `grátis`
- [Lei Brasileira de Inclusão](https://go.mymarketing.click/iaaula-lei-brasileira-de-inclusao) - O Estatuto da Pessoa com Deficiência, base da atividade adaptada. `oficial` `grátis`
- [Lei do piso do magistério](https://go.mymarketing.click/iaaula-lei-do-piso-do-magisterio) - A Lei 11.738/2008, que institui o piso salarial do professor. `oficial` `grátis`

## Proteção de dados

A lei e a autoridade que valem para os dados de clientes e alunos.

- [LGPD](https://go.mymarketing.click/iaaula-lgpd) - A Lei Geral de Proteção de Dados, no texto compilado do Planalto. `oficial` `grátis`
- [ANPD](https://go.mymarketing.click/iaaula-anpd) - A Autoridade Nacional de Proteção de Dados, com guias e regulamentos da LGPD. `oficial` `grátis`

## Etiquetas

Cada item diz o que é. As etiquetas ao lado ajudam a escolher: oficial quando vem de quem define o padrão, código aberto quando o código está publicado, grátis ou pago pelo modelo de uso, API e SDK pelo jeito de integrar. Os itens com a etiqueta "do autor" são feitos por Ciro Cesar Maciel e seguem as mesmas regras de todos os outros.
